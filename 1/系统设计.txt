# 小型酒店管理系统 - AI生成框架步骤（纯文字描述）

## 一、 系统概述

本项目是一个基于**Vue 3.22.2 + Spring Boot 4.0.3**前后端分离的小型酒店管理系统，采用手机号作为用户唯一标识和登录账号。系统分为三个独立客户端：**管理员端、商家端、用户端**。

**开发顺序**：先完成前端页面模块，再完成后端接口模块。

## 三、 AI生成框架步骤

### 第一部分：前端页面模块生成（先执行）

#### 步骤1：前端项目初始化

**提示词模板：**
```
请帮我生成一个基于Vue 3.22.2 + TypeScript + Vite的前端项目，项目名称为H-Frontend。

要求：
1. 使用Vite作为构建工具
2. 启用TypeScript严格模式
3. 支持JSX语法（需要@vitejs/plugin-vue-jsx插件）

项目目录结构需要包含：
- src/api/：API接口层（含modules子目录）
- src/assets/：静态资源
- src/components/：公共组件（含common和layout子目录）
- src/composables/：组合式函数
- src/router/：路由配置
- src/stores/：Pinia状态管理
- src/types/：TypeScript类型定义
- src/utils/：工具函数
- src/views/：页面视图（含admin、merchant、user、login、register子目录）
```

#### 步骤3：TypeScript类型定义生成

**提示词模板：**
```
请生成TypeScript类型定义文件，放在src/types目录下：

1. user.ts：
   - User接口：phone、realName、idCard、role、status、avatar、registerTime、lastLoginTime
   - Merchant接口：id、phone、contactPhone、address、shopDescription、auditStatus、auditRemark
   - LoginParams接口：phone、password
   - RegisterParams接口：phone、password、realName、idCard

2. hotel.ts：
   - Hotel接口：id、merchantPhone、hotelName、hotelType、address、city、district、hotelPhone、description、facilities、checkInTime、checkOutTime、status、auditStatus、coverImage、images、totalScore、commentCount
   - RoomType接口：id、hotelId、roomTypeName、capacity、bedType、area、hasWindow、facilities、quantity、price、images、status
   - HotelSearchParams接口：city、checkInDate、checkOutDate、keyword、minPrice、maxPrice、facilities、sortBy、page、size

3. order.ts：
   - Order接口：id、orderNo、userPhone、merchantPhone、hotelId、hotelName、roomTypeId、roomTypeName、checkInDate、checkOutDate、nights、roomCount、unitPrice、totalAmount、actualAmount、guestName、guestPhone、specialRequest、paymentMethod、status、payTime、cancelTime、cancelReason、createTime

4. common.ts：
   - PageResult<T>接口：list、total、page、size
   - ApiResponse<T>接口：code、msg、data
```

#### 步骤4：Axios请求封装

**提示词模板：**
```
请封装Axios请求模块（src/utils/request.ts），要求：

1. 创建axios实例，baseURL为'http://localhost:8080/api'，超时时间10秒

2. 请求拦截器：从localStorage获取token，添加到请求头'satoken'

3. 响应拦截器：
   - 响应码200：返回response.data
   - 响应码401：清除token，跳转登录页，提示"请重新登录"
   - 响应码403：提示"无权限访问"
   - 其他错误：提示错误信息

4. 导出GET、POST、PUT、DELETE泛型方法
```

#### 步骤5：路由配置和守卫生成

**提示词模板：**
```
请生成路由配置（src/router/index.ts）和路由守卫（src/router/guards.ts）：

路由定义：
- /login：登录页
- /register：注册页
- /admin：管理员布局（重定向到/admin/dashboard）
  - /admin/dashboard：仪表盘
  - /admin/user：用户管理
  - /admin/merchant-audit：商家审核
  - /admin/hotel-audit：酒店审核
  - /admin/order-monitor：订单监管
  - /admin/system-config：系统配置
- /merchant：商家布局（重定向到/merchant/dashboard）
  - /merchant/dashboard：数据看板
  - /merchant/hotel：酒店管理
  - /merchant/room-type：房间管理
  - /merchant/order：订单处理
  - /merchant/check-in：入住登记
  - /merchant/comment：评价管理
- /user：用户布局（重定向到/user/hotel）
  - /user/hotel：酒店搜索
  - /user/order：我的订单
  - /user/favorite：我的收藏
  - /user/profile：个人中心

路由守卫逻辑：
1. 检查localStorage是否有token
2. 无token访问需要登录的页面，跳转/login
3. 有token但角色不匹配，跳转到对应角色的首页
4. 账号被冻结时，跳转到冻结提示页并退出登录
```
